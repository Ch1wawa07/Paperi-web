# 八项原始验收反馈修复记录

本次完整阅读用户 ZIP 内的 Markdown，并逐张查看截图 01–08；八条原话不改写。基线为真实 HEAD `0d39b78`，在 `codex/paperi-stage1` 保留已有成果继续修改。

## P0 诊断与证据

1. 精析和综述共享 `requestStructured`。旧代码将 `finish_reason != stop`、缺少最终回答和协议错误统一报为同一句错误。工作流十维度允许每维 600 字却仅有 5000 输出 token；达到上限的回答被拒绝，用户看不到原因。2026-10-26 查看 [DeepSeek 官方 Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/) 和 [思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)，确认当前思考模式默认开启。旧请求没有设置模式，这是增加耗时和预算耗尽的风险。**没有用户当次上游响应日志，不能断定截图一定是 length 或思考预算耗尽**。
2. 方向正文污染可直接从代码确认：逐字 quote 核对失败时，服务端把 body 替换成“无法从本次提供的原文核对…”，客户端选择方向时又将 title + body 保存。现在错误状态独立，旧诊断文字不会进入活动主题、AI 上下文或框架导出，原始历史仍保留。
3. PDF 原先按页顺序仅取开头 24000 字；长论文后半部方法和结论没有传给模型。现在精析最多 40000 字，并分配给首尾和含方法/结果/讨论标题的页面，保留真实页码。仍是有界节选，不声称读过全文。
4. 检索词状态只在组件首次挂载读取，选概念后未生成检索准备就显示四个空框。现在直接派生并显示当前已选概念、复用已有 AI 关键词；用户可一键生成补充建议，无需重复输入。
5. 文件 input 原先没有 multiple，处理器只取 files[0]。现已支持混合多选和拖入，按文件独立报错、统一预览确认；新 PDF 写入失败只清理本次新文件，不删除已有原件。
6. 星图只按 DOI/OpenAlex ID 请求 OpenAlex，AI 不提供引文边；PDF 导入并不会自动取得这些标识或学术出版元数据。缺数时旧画布只有孤点，这是数据能力受限而非切换方向失效。现将限制及补救动作放在画布之前，支持查看已上传 PDF 的参考文献原文作为人工核对线索（不转换为认证引用边）。

## 修改范围

- 官方 DeepSeek 主机的结构化请求显式关闭思考模式（保留用户选择的模型，旧 reasoner 不强行关闭），其他供应商不加入专有参数。保留 `AI_API_KEY` 优先及 `DEEPSEEK_API_KEY` 回退配置。每次点击一次模型请求，不自动重试或换付费服务。
- 工作流输出每维最多 180 字，预算 6500；分别提示截断、空内容/仅推理、协议、JSON、HTTP 400/404、权限、余额、限流及超时。不会把 reasoning_content 当成最终分析，也不会保存残缺 JSON。
- 默认“一键精析”“一键生成研究方向”，追问折叠为可选；显示资料层级及 PDF 已提取页数/字数。方向提议与原文事实分开标注，不能核对的事实维度不采纳；原文匹配仅做 NFKC/空白归一，不改写引句内容。
- “我的研究方向”独立展示已选内容和文献，编辑框占满可用宽度。历史中的旧错误原文不删除，但不再作为活动主题继续传播。
- 多文件一次最多 20 个，PDF 逐个最多 60 秒，保留既有单文件尺寸/页数限制。混合 RIS/BibTeX/EndNote/TXT/PDF；不支持和解析失败的文件独立显示，已成功的记录可继续导入。确认按钮按实际跳过/保留数量显示。
- 检索准备先显示概念和复制卡片、学校图书馆入口，再提供可选编辑；AI 生成后保存，失败保留概念。没有自动付费调用。
- 综述 AI 失败仍明确报错，可另外生成**不调用 AI 的可编辑结构草案**并保存、进入设计、导出。骨架不归纳论文发现，节点明确标注未分析，不算 AI 成功。
- 星图增加真实连接数为零的解释、元数据编辑入口、PDF 参考文献原文查看；点状背景、分层柔光、聚焦/入场效果和减少动画偏好。仍不造连线。

## Mac 最短真实复验

1. 在 GitHub 目标分支下载 ZIP，保留旧目录、浏览器数据，`.env.local` 仅本地复制，`npm ci` 后 `npm run dev`，保持同一 `localhost:3000` 和浏览器。不要把密钥放入聊天、截图或 NEXT_PUBLIC 变量。
2. 保留已有 `AI_API_KEY/AI_BASE_URL/AI_MODEL`；或在 `.env.local` 配置服务端 `DEEPSEEK_API_KEY`。默认官方模型为 deepseek-flash。自定义 base 为兼容 API 根路径，**不含** `/chat/completions`。不自动更换已有付费模型。
3. 一次选 3 篇实际论文（含文字型 PDF），在导入预览检查每篇页数/字数和基本书目；确认入库无需调用 AI。选其中 PDF，“一键精析”只点击一次，核对方法/结论引句和 PDF 页码。失败提示应明确截断/协议/JSON/权限/超时等原因；不要连续盲目重试。
4. 选 3 篇 → 一键生成方向 → 选择方向 → 研究整合生成综述结构。初次真实联调仅这 3 次模型调用；查看服务商账单确认实际费用，不按模拟结果估算成功成本。失败则先保留当前项目和具体响应错误（不要提供 Authorization 请求头）。
5. 验证刷新后方向/提纲仍在，继续设计并导出。即便 AI 不可用，也能单独选择本地结构草案继续编辑；这是降级路径，非真实 AI 联调通过。
6. 星图用一篇确认在 OpenAlex 中的真实 DOI 测一次；同时测试缺 DOI 的中文论文。前者也可能受 API 权限或网络影响，后者应显示缺数说明，不能当作有真实连接。
