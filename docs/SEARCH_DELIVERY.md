官方公开 Search/Fetch，使用 API Key Bearer 鉴权。Paperi 固定调用官方 https://api.deepseek.com/v1/tools/search 与 /fetch，不发送其他平台密钥。账号是否有权限仍以实际请求为准。

Search 与 Fetch 各 $0.75/千次成功且有内容的请求；失败、空结果、超时依文档不收费。工具集成的暂时免费说明不作为 Paperi 直接调用的免费承诺。模型分析另按所选模型 token 计费；不充值、不接入额外平台。

## 实现

- 默认文献发现改为 DeepSeek 网页搜索。元数据查询保留用于显式辅助查询、已知 DOI 的导入/核验及真实引用关系；不自动回退冒充搜索成功。
- 输入 2–200 字自然语言问题，附带本项目已选概念。智能模式最多 2 次 Search，中文优先及英文补充交替取样；单语言模式 1 次。每次返回最多 10 条。查询受官方 128 字符限制，原始输入仍保留在项目历史。
- 无自动分页或重试；必要时最多 1 次 Fetch；最多 3 次精确 DOI 登记核验。单进程 5 分钟缓存、40 项上限，合并进行中的相同检索。批量相关性分析沿用现有接口并缓存 5 分钟；无密钥时明确失败。
- 三种状态：登记元数据、待核实论文线索、参考网页。网页日期不充当论文年份；简介不充当论文摘要；搜索分数不充当引用数。缺失作者、年份、期刊和 DOI 如实提示。
- 线索仅在 DOI 登记身份、题名及基本身份字段匹配时升级。译名、网页标题后缀等可能导致保守地不升级；没有实现通用出版网站字段解析、标题模糊核验或中文数据库全文访问。
- 相关性五档；理由包含研究内容/问题联系、建议用途、依据及限制。缺少论文摘要不会标为直接相关。用户可展开低相关与信息不足结果。网页文本作为不可信研究资料输入，不是模型指令。
- 收藏、研究脉络与设计沿用原项目数据结构及存储键。旧 Crossref/OpenAlex 记录继续读取。新线索可收藏及加入设计，但不能被当作已验证证据；无 DOI/OpenAlex ID 的记录在星图选择中提示真实关系暂不可用，不补造连线。

## 安全配置与 Mac 更新

不要把密钥发到聊天或提交 Git。Mac 在工程根目录复制 `.env.example` 为 `.env.local`，在编辑器里填 `DEEPSEEK_API_KEY`。文件已经被 Git 忽略，变量不能加 NEXT_PUBLIC_ 前缀。已有 AI 配置可以继续使用；仅配置 DeepSeek 密钥时，模型默认采用官方文档的 deepseek-flash，相关性分析会收费。也可显式填写 AI_MODEL 选择你账号已有的模型。

云端在环境 Secrets 中设置同名变量；不要在命令行写明文密钥、打印环境变量或上传 `.env.local`。网络设置需要允许 api.deepseek.com，辅助核验/引用需要 api.crossref.org、api.openalex.org 及 doi.org；当前环境名单未包含这些服务域名，配置后仍需确认网络权限。重启服务后生效。

Mac 更新：先停止本地服务，在现有工程运行：

```sh
git status --short
git fetch origin
git switch codex/paperi-stage1
git pull --ff-only origin codex/paperi-stage1
npm ci
npm run dev
```

如有本地改动，先自行备份，不执行 reset/clean。保持原浏览器与原访问网址/端口，避免本地项目看似丢失；不清空 localStorage。不要将云端 localhost 当作 Mac 地址。

真实验收时逐个搜索三个原始主题，记录来源页面、真实性状态、相关性理由及缺失信息；每主题只搜索一次，先检查 DeepSeek 控制台调用记录再决定是否补测。任何主题无相关论文也应如实记录，不用预置结果替代。
