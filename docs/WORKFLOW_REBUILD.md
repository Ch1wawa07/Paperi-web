# Paperi 研究工作流重构

基线：`76370b7`，分支：`codex/paperi-stage1`。本次以用户上传的工作流重构需求为准，替代此前网页学术搜索定位。没有重新初始化工程。

## 架构审计与实施结果

原有项目仓库、探索对话、概念确认、乐观版本检查、元数据适配器和研究设计画布可以复用。原 `Paper` 只接受外部来源，默认搜索结果进入工作台，引用图是单中心，分析没有统一资料版本，这些与新旅程不相容。

按“存储与身份 → 导入/PDF → 工作台 → 多中心网络 → 分析与综述 → 设计导出 → 回归”实施：

- 保留 `paperi.projects.v1` 和 snapshot version 1，新增可选 `workflow`（自身 version 1），旧项目不需要破坏性迁移。保存仍检查项目快照与模块 revision；冲突和配额不足不覆盖旧内容。
- `Paper.source=import` / `identity=imported` 专门表示用户题录；有 DOI 也不会自动标成核实。外部登记资料与 AI 分析分别存放。旧 OpenAlex、Crossref、academic 及历史网页收藏仍可读取。
- 工作流保存检索准备、资料集合、研究方向、分析历史及输入快照、综述节点、引用网络布局和视图、框架确认指纹。全文 Blob 与逐页可提取文字放 IndexedDB `paperi.files.v1`，localStorage 只保存文件关联及摘要信息。
- 来源指纹包含问题、概念、关键词、所选集合、题录及 PDF 版本、方向。分析和综述不静默覆盖；变更后标记历史。删除资料的引用明确显示“来源已移除，需要更新”，旧设计引用快照不再冒充现存依据。
- `discovery-server.ts` 已删除；旧 `/api/literature/discover` 仅返回 410，不调用 Search / Fetch。OpenAlex / Crossref 辅助端点保留，用于登记核对和引用关系，主界面没有网站搜索框。

## 可操作的完整路径

1. 首页创建项目或写下想法进入灵感实验室；原对话、概念选择及编辑保留。
2. 检索准备生成/编辑中文核心词、同义扩展词、英文词及组合，可逐行删除、复制和保存。默认学校图书馆为 https://www.lib.szu.edu.cn/ ，允许保存其他 HTTP(S) 图书馆地址，在新标签打开。
3. 文献工作台 → 导入文献。RIS、BibTeX、EndNote 标签题录、规范逐行参考文献（`作者. 题名[J/D/C]. 出版来源, 年份`）先解析预览。可修改字段；列出失败原因、缺失字段和潜在重复。UTF-8 优先，乱码时尝试 GB18030。
4. 去重优先 DOI / OpenAlex ID；无 DOI 时仅将同题名、同年且存在共同作者的记录列为可能重复。不同译名不自动合并。可跳过、独立保留、合并补充缺失摘要；合并保留原题录、笔记及分类，不猜测冲突字段。
5. 文献可编辑题录、摘要、笔记、多分类，分类可新增/改名/删除。DOI 登记核对显示候选，用户比较后才采用；修改已认证记录的内容后降为用户题录。删除需确认，可取消，其他项目不受影响。
6. PDF 可直接上传后确认题录，或附加在已导入文献上。实际使用 PDF.js 提取文字；不把文件名/PDF 属性当作已核实元数据。保存后刷新可读，支持下载原文件及移除关联；扫描件、超限或损坏文件明确报错。
7. 星图、研究脉络、文献精析为平行入口。星图始终显示一级文献，按需每次加载最多 3 篇有 DOI / OpenAlex ID 的文献，每篇最多 6 条参考、6 条施引结果，画布最多展示 80 个二级节点。合并共享节点与有出处的边；导入题名与 DOI 登记题名不一致时要求先核对。每条边可看引用方 OpenAlex 记录。二级节点入库后变为一级，不重复。支持拖动、缩放、平移、邻边高亮、方向切换、收起二级、保存节点布局和 SVG 导出。
8. 研究脉络默认当前库全部资料，可取消勾选；每次 AI 最多 30 篇，超过时要求分组。返回最多 3 个有来源的方向，可拒绝、追问、选择、编辑，也可自行输入。
9. 单篇精析有 10 个折叠维度。仅书目时确定性返回有限主题说明和信息不足，不调用模型补猜；摘要或 PDF 节选分析的原文 quote 必须匹配实际输入，PDF 引用必须有匹配页码。可存为笔记、理论候选、综述依据或设计参考。每次保存分析来源 ID、输入快照和版本指纹。
10. 研究整合的综述地图和提纲是同一份可编辑数据。添加、删除、改内容、上下调序、关联文献、拖动布局均可操作；AI 候选先预览，再追加，保留已有编辑。支持 Markdown 与 SVG。
11. 复用定量/质性设计画布；路径切换需确认且保留已有内容。节点、类型、变量说明、H1 等关系标签、依据、确认状态、坐标与连线可编辑。虚线表示研究假设/规划，不表示引用或已证实因果。
12. 研究框架页面确认当前版本、导出 Markdown，包含方向、综述、文献、设计、假设关系、待核查事项和可编辑模型 JSON；模型 SVG 在画布导出。资料变化后确认状态失效。
13. 首页可备份全部项目 JSON，恢复前验证，恢复为新副本，不覆盖已有项目。PDF 原件单独备份并重新附加；恢复副本不能删除原项目文件。

## 有意限制与未实现的高级能力

- 没有把本工具包装为中文学术数据库；不承诺全部中文论文的引文覆盖。当前引用关系仅按 DOI / OpenAlex ID 匹配，**没有无标识标题模糊自动匹配、PDF 参考文献自动抽取/认证、多跳递归扩展**。无匹配时保留一级节点和明确状态，不画假边。
- PDF 在本浏览器本地保存，清除站点数据、换浏览器/网址/端口可能不可用；JSON 不含 PDF Blob。没有云同步、OCR、扫描件识别或复杂版式恢复。可提取 PDF 上限 20 MB / 150 页 / 60 万字符。中文缺字、阅读顺序不可靠时请补充可信摘要并核对原文件。
- AI 不是全文阅读器：每篇最多发送 24,000 字符的前部逐页节选，多篇共享 60,000 字符 PDF 预算；摘要加全文总输入另有限额。关键结论需自行核查，quote 存在不证明模型解释正确。不会用上轮 AI 正文充当新证据。
- RIS / EndNote 常用标签及常见嵌套 BibTeX 字段已支持；不支持 BibTeX 宏展开、LaTeX 复杂转义的完整排版、所有平台自定义格式、任意自由文字引用风格或 CSV。错误记录可更换标准导出格式重试。
- 每项目 300 篇、30 分类；每次 AI 30 篇；分析历史 100 次、综述/设计节点各 60。到限明确报错，不静默丢旧内容。本地存储总容量取决于浏览器，完整输入快照会占用容量，请定期备份。
- 普通用户导入题录的“真实存在”由其来源提供，未经外部认证的记录明确标记，AI 不代替真实性审查。
- 没有整篇论文自动写作。用户确认表示接受计划，不是学术结论认证。

## Mac 更新（你此前使用 GitHub ZIP）

1. **先在旧版同一浏览器里保留项目数据**。若旧版尚无备份按钮，可先保留旧项目文件夹和浏览器数据；不要清除 localhost 的站点数据。更新后立即用首页备份按钮下载 JSON。
2. 在 GitHub 仓库选择 `codex/paperi-stage1`，Code → Download ZIP，解压为一个新文件夹。保留旧文件夹作为回退，不覆盖或删除它。
3. 将旧文件夹的 `.env.local` **仅在 Mac 本地**复制到新工程根目录。Finder 可用 Command+Shift+. 显示隐藏文件。不要上传、发聊天或提交此文件。
4. 终端进入新文件夹，使用 Node >=22.13（建议 Node 24），执行：
   ```bash
   npm ci
   npm run dev
   ```
   `npm ci` 会从已锁定版本安装 PDF.js 并复制本地 worker，无运行时 CDN。
5. 先用 Control+C 关闭旧服务，仍访问原来的 `http://localhost:3000`，使用同一个浏览器配置。不同时运行让新服务自动改成 3001；域名/端口变更会隔离浏览器存储。
6. 新版能读取旧项目。先下载 JSON 备份，再试导入一小批资料。旧版程序不理解新版 import 题录，所以不要直接用旧版保存已含新题录的浏览器数据；需要回退时保留备份并独立浏览器测试。

已有完整 `AI_API_KEY` + `AI_BASE_URL` + `AI_MODEL` 配置继续使用。本轮没有更改模型选择机制。若使用 DeepSeek 官方配置，请在 Mac 的 `.env.local` 本地设置真实 key、官方 base 和账户实际可用 model（参考 `docs/AI_SETUP.md`），重启服务。不要混用残留第三方 base 与官方密钥。无需 Search/Fetch 权限；只调用模型聊天 API。缺少密钥仍能导入、管理、画图、手工整理和导出。

真实验收建议：创建品牌联名项目 → 生成一次关键词 → 到学校数据库获取十篇真实题录 → 批量导入 → 为一篇补真实摘要或文字 PDF → 仅对这组资料生成一次研究方向和一次精析 → 核对原文引用、资料层次和限制 → 试一篇有 DOI 的引文关系 → 编辑综述与定量设计 → 导出 → 删除一篇作为依据的文献检查失效提示 → 切换项目并刷新确认隔离。不要用测试目录题录证明学术效果。
