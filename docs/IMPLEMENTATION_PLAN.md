## 风险与处理

- **本地数据丢失**：界面与 README 明示保存范围与清理风险；不承诺云同步。阶段 2 迁移需用户确认导入规则并验证数据归属。
- **密钥与费用**：阶段 1 完全不调用外部 AI；后续采用服务端环境变量、输入长度/请求限额和错误处理，不自动购买资源。
- **AI 建议可靠性**：研究种子需用户主动采纳，AI 不覆盖用户确认内容；建议、确认、文献依据、待核实需分开标注。
- **学术数据覆盖及配额**：后续验证 OpenAlex 当时认证政策和中文覆盖，不依赖文档中对匿名访问的假设；处理 429、超时、空结果，缺失不补造。
- **多标签页写入**：本阶段有同步和修订检查，但 localStorage 无数据库事务；后续由数据库与冲突规则保证一致性。
- **展示期限**：需求中的课堂目标为 2026-10-30。按可验证闭环推进，不以假数据或越阶段开发填补进度。
- **预览可达性**：云端服务不等于公开网站；本次用真实浏览器截图验收，外部交互预览需平台提供私有端口能力或在本机运行。
