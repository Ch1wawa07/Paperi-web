# Paperi · Soft Glass 视觉改版

本轮依据用户提供的磨砂玻璃 UI 参考重做阶段 1 前端，业务范围不扩展。

## 设计方向

- 浅雾灰工作台、深海蓝主卡，青蓝、紫粉与珊瑚色从材质内部透出。
- 卡片采用较大的圆角、渐隐的内高光边缘、细颗粒和局部背景模糊，保持平面磨砂质感与文字清晰度。
- 顶部胶囊导航替代固定侧栏。桌面采用主输入区与真实项目区双栏，研究流程入口排在下方；手机切换为单栏与折叠菜单。
- 首页品牌装饰是原创玻璃花瓣，延续“让好奇慢慢有形”的概念。保留 Paperi 的叶片标识；没有借用参考作品的品牌、统计值或图表。
- 五个流程入口的点阵数字仅是入口序号；所有 AI、学术数据与导出能力仍明确标注未接入。
- 业务空页面、项目卡、原生弹窗、表单、错误与反馈统一使用同一视觉系统。

## 实现与边界

样式在 `src/app/globals.css`；玻璃花瓣在 `src/components/glass-art.tsx`，颗粒来自本地 `public/grain.svg`。无需新增依赖、远程图片、字体服务或 WebGL；文字与按钮保持真实 HTML。

装饰不接收点击，辅助技术忽略纯装饰。保留键盘焦点、原生弹窗焦点管理、移动端导航以及 reduced-motion 支持。

项目数据格式和保存逻辑沿用阶段 1，无需迁移，不会因本次改版清除本地项目。验证覆盖 1440 / 1280 / 768 / 390 像素与原有项目操作；没有进入阶段 2。

真实运行效果见 [截图预览](PREVIEW.md)。

## 材质微调

保留已确认的布局、配色与阶段 1 功能，仅调整全局 CSS：

- 移除叠加的窄亮边，降低边框与投影对比，用较宽、较淡的内侧漫射光形成柔和边缘。
- 扩大青蓝、紫粉与珊瑚光晕的过渡范围；增强背景层细颗粒，文字不参与模糊。
- 降低花瓣、中心小球和辅助装饰的镜面反射；仅装饰使用轻微模糊。
- 弱化表单和项目卡的凸起感，入口悬停上移由 6px 收到 2px；保留焦点提示。

材质细节和完整页面均由实际浏览器截图记录。
