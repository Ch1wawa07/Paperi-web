# Paperi · 晕染磨砂视觉

基于用户提供的参考图调整阶段 1 前端：色彩更丰富但色系统一，边缘弥散，保留明显的细颗粒磨砂感，布局与文字更精简。

## 版面与文案

- 首页灵感卡片在 1440px 桌面宽度下为约 342px 高，较上一版 498px 缩短约 31%；390px 手机宽度下约 294px 高。
- 保留一句提问「此刻，有什么新想法？」与真实输入框，按钮简化为「保存灵感」。
- 项目空状态改为紧凑的横向组合；研究入口精简为名称和一句短说明，未接入状态统一放在入口区标题旁。
- 桌面双栏、平板双栏及手机单栏与折叠菜单保留；项目列表可滚动，支持长名称。

## 材质与色彩

- 蓝紫与青色作为共同底调，粉色、珊瑚与暖橙作为局部晕染；采用多层椭圆渐变错位融合。
- 颗粒位于内容下方，柔焦只作用于边缘装饰层；文字、输入和焦点提示保持清晰。
- 组件边缘使用宽而柔和的雾光，降低外轮廓对比；五个研究入口使用更圆润的比例。
- 立体花瓣替换为细线与光点构成的原创抽象轨迹，作为灵感意象，不表示统计或研究关系。
- 项目管理、业务页面、弹窗与手机端共用同一材质系统。

## 实现与验证

主要文件为 `src/app/globals.css`、`src/components/home.tsx` 和 `src/components/glass-art.tsx`；颗粒继续使用本地 `public/grain.svg`。没有新增依赖或外部资源。

保留真实项目创建、保存、改名、删除和跨页恢复。未修改数据结构和存储逻辑。辅助技术忽略纯装饰，保留键盘焦点、减少动画、原生弹窗与数据异常反馈。

原有 13 项浏览器测试只更新了文案定位，行为断言保留；验证包含 1440 / 1280 / 768 / 390 像素布局和六页导航。没有进入阶段 2，也没有公开部署。

真实运行效果见 [截图预览](PREVIEW.md)，验证细节见 [测试记录](TEST_RESULTS.md)。
