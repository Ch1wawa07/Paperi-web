# 学术文献身份筛选修复

基线：`codex/paperi-stage1` / `8aa7df7`。日期：2026-10-25（北京时间）。

## 根因和改动

旧实现将 Search 网页直接映射为 Paper，并把普通网页、含“论文/摘要”等词的宽松线索混入最终 items。此前测试甚至要求这些线索可收藏，因此没有拦住真实使用中的新闻结果。本次移除这一数据通路，而非只修改提示。

新流程：

1. 最多 3 次针对学术出版记录的 Search，`need_content:false`。扩展 AIGC/GEO 等常见简称，短剧规范为微短剧，附带期刊/学位/学术研究限定与知网/万方/维普定向查询。没有任何主题预置论文结果。
2. Search 结果仅是候选 URL 与题名；简介、网页日期、权威度、排名均不作为论文元数据。新闻站点及学术站点的新闻/列表/介绍页在候选阶段排除。
3. 最多核验 6 个受支持的学术详情记录。读取实际详情 HTML 的 citation 元数据或本记录 ScholarlyArticle/Thesis JSON-LD；必要时最多 2 次 DeepSeek Fetch，读取详情中的明确出版字段或知网期刊门户头部。身份核验阶段总等待上限 65 秒，无自动重试。
4. 题名、作者、出版年份、期刊/机构/会议、具体学术记录链接缺一则排除。DOI 不是必需条件；没有 DOI 时记录 URL/库内标识和字段来源保留在 verification 中。直接 DOI 候选通过 Crossref 登记记录与题名准确匹配核验，并检查文献类型与基本书目字段。仅有注册 DOI、缺失出版信息也不能通过本次发现入口。
5. 只有通过身份关的论文才进入 items，之后才做批量相关性分析。前端还有独立身份过滤及新增收藏检查。0 篇合格结果返回空数组，显示“本次搜索尚未找到可核实的学术文献。”
6. 相关性分析只使用真实题名与实际论文摘要，不把 Search 简介送入模型当摘要。失败展示服务端错误，并可只重试相关性，不重新 Search/Fetch。无摘要的直接相关判断降为可能相关，明确只凭题名。

5 分钟缓存、并发与请求上限仍保留；不会每输入一个字就调用，也不会自动翻页或充值。最多 3 Search + 2 Fetch，按此前官方标价估算工具费用上限 $0.00375/次搜索，另计批量模型 token。实际价格以 DeepSeek 控制台为准。详情 HTML 核验不增加新的付费平台。

## 来源覆盖与限制

支持受约束的知网、万方、维普、国家科技期刊平台详情 URL，以及高校/科研机构、部分学术出版社的常见期刊和论文库详情路径。域名只是决定是否尝试读取的条件，不能直接确认为论文；最终必须存在具体出版字段及本记录身份。

标准元数据与明确标签优先，未通过解析的站点、登录/验证码、动态渲染、缺作者/年份/出版信息、超时均保守排除。因此结果可能少于搜索实际包含的论文；不宣称覆盖全部中文数据库。没有 PDF/全文解析、付费数据库抓取或通用网站爬虫。检索出来的论文不保证与主题直接相关，相关性是第二关。

没有改动原 localStorage 键或项目结构，也不自动删除此前收藏的网页线索、笔记、设计来源。这些历史数据继续读取并标注原身份；不能通过本次发现入口新增为正式学术文献。新型无 DOI 学术记录可收藏、参与脉络/设计；没有 OpenAlex ID/DOI 时真实引用星图继续提示不可用，不生成连线。

## Mac 更新和真实验收

停止服务，保留现有项目目录和浏览器访问地址。先 `git status --short`；如有个人改动先备份，不 reset/clean。然后：

```sh
git fetch origin
git switch codex/paperi-stage1
git pull --ff-only origin codex/paperi-stage1
npm ci
npm run dev
```

密钥只放本机被 Git 忽略的 `.env.local` 或云环境 Secrets。完整原 `AI_API_KEY`/`AI_BASE_URL`/`AI_MODEL` 继续生效；官方 DeepSeek 原配置可复用密钥，第三方兼容地址需单独配置官方 `DEEPSEEK_API_KEY` 供 Search/Fetch。不要将真实密钥发送到聊天、写入命令历史或 Git，也不要把不完整的旧地址/密钥配置与新密钥混填。修改后重启服务。

逐个主题各点击一次检索即可开始验收，先不反复重试：

1. 打开开发者工具 Network，查看 `/api/literature/discover`：items 中不得出现普通网页或只有搜索简介的线索，必须有作者、年份、出版来源和核验记录。0 篇也应如实记录。
2. 对每张卡打开原始学术记录，逐一核对题名、作者、年份、期刊/机构；无 DOI 也应有可核验库内详情标识。不要把新闻引用了一篇论文视为新闻本身是论文。
3. 查看相关性理由与依据，缺摘要时应保守；失败时显示具体错误，单独重试不能再发 Search 请求。
4. 在两个项目分别收藏/刷新/切换，检查笔记和历史隔离；新论文加入设计，旧项目设计仍在。无真实引用数据时不得出现新造连线。
5. 在 DeepSeek 控制台核对调用次数及余额。每次最多 3 Search + 2 Fetch；无穷分页/重试不应发生。

本轮尚无密钥，因此不能给出这三个主题的命中数量或相关论文质量结论。请把 Mac 上实际响应及错误（先移除密钥/Authorization）作为后续真实验收依据。
