# Paperi 技术决策记录

## 2026-10-20 · 阶段 1

1. **保持唯一工程。** 起始仓库只有 README，当前 `work` 分支干净，HEAD 与远端 main 同为 `5bc1215`。直接在仓库根目录建立 Next.js 工程，未另建仓库或 worktree，未推送、公开部署或购买服务。
2. **框架与依赖。** 采用 Next.js App Router、React、TypeScript strict 与 Tailwind 4。`package-lock.json` 锁定版本，使用 `npm ci` 复现。阶段 1 不安装 Supabase、AI SDK、图可视化库，避免尚未使用的依赖。Playwright 仅为开发测试依赖。
3. **本地优先但不宣称云同步。** 未提供 Supabase 配置，使用异步 `ProjectRepository` 数据访问接口与 localStorage 实现。保存项目 id、名称、领域、状态、起始观察、创建/更新时间，以及当前项目。服务端预渲染不访问浏览器存储；客户端读取完成前显示加载且禁用创建。
4. **失败不冒充成功。** 写入成功才更新共享状态；对 JSON、版本、字段与日期进行校验，读取异常不删除原数据；写入失败保留原状态。多标签页通过 storage 事件同步；修订号检测过期写入。localStorage 并非事务型多用户存储，同时写入的强一致性由后续数据库实现。没有自动清空或无确认恢复出厂按钮。
5. **诚实的阶段边界。** 首页自然语言观察只用于创建本地项目，在灵感实验室按用户原文展示，不当成 AI 分析或已确认研究种子。五个模块说明后续接入阶段；无假论文、关系图、热点或结果。所有可点击控件提供真实操作，未实现操作使用文字说明而非假按钮。
6. **视觉与可访问性。** 奶白、深海蓝、青/紫/粉玻璃质感，原创 CSS 纸张与萌芽装饰，无外部素材或字体网络依赖。正文采用高对比实色背景。原生语义导航、表单与 dialog 支持焦点管理、Escape、删除默认聚焦取消、跳到正文、状态播报及 reduced-motion。响应式断点保证手机导航可用。
7. **未来服务配置。** `.env.example` 只记录空占位，`.env.local` 等均被忽略。当前不发起外部 AI/文献请求。阶段 2 才确定供应商、服务端限额和数据迁移；禁止前端服务端密钥与无 RLS 公共数据库写入。
8. **预览与测试。** 用本地生产服务与系统 Chromium 做浏览器测试，不以进程存活替代功能验证。本环境没有可用的外部预览工具，不制造上线 URL；提供真实截图和菜单式本机启动步骤。初学者可用 VS Code 任务，无需输入代码。

9. **框架生成的维护指引。** Next.js 首次开发启动自动生成 `AGENTS.md`，保留该版本配套的维护说明，方便后续开发按已安装版本的文档工作。

## 2026-10-20 · 用户确认 UI 后的阶段 2 接入准备

1. 用户确认沿用当前 UI，随后明确表示尚无 API，要求先完成接入准备并提供配置步骤。保留视觉基线，不购买服务或公开部署。
2. 使用服务端 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL` 配置 OpenAI 兼容 Chat Completions + JSON object 接口；无默认收费模型。当前配置为空，真实调用未验收。
3. 供应商地址只来自服务端配置，外部地址要求 HTTPS；仅本地测试允许回环 HTTP。限制输入、输出、响应大小与等待时间，不自动重试；密钥不进入客户端和错误详情。
4. 基于当前进程维护并发、分钟、小时、日调用上限。它是开发期保护，重启会重计数；公开或多实例部署需要身份、共享配额与服务商预算，当前不部署。
5. `Project.exploration` 为可选新增字段，旧阶段 1 项目可直接读取；包含对话、候选方向和显式确认的研究种子及版本。数据校验失败时保护旧记录，不自动清空。当前仍仅本地保存。
6. 每次 AI 提问先保存用户消息；有效回复才追加历史和候选。确认的研究种子不受聊天更新影响；替换需显式确认。跨标签修订冲突不静默覆盖，收到但未保存的回复另行标明。
7. 不具备 Supabase 配置，未创建数据库、添加数据库 SDK 或宣称云同步。匿名认证、RLS 和旧数据导入规则待条件具备后单独验证。
8. 自动测试显式清空真实密钥，使用隔离的本地服务或浏览器请求拦截验证流程，产品代码没有模拟回复分支。真实两个话题的 AI 验收仍待配置，不能用夹具测试代替。


## 2026-10-21 · 阶段 3 真实文献与人性化收藏

1. 用户明确要求真实可查、相关与来源质量优先。论文只由固定官方 OpenAlex / Crossref 接口提供，AI 仅建议中英文检索词，不生成参考文献。未读付费全文时不推断全文结论。
2. 默认相关性排序 + 期刊 / DOI / OpenAlex 标记的 CWTS 核心来源。`is_core` 是公开元数据筛选依据，不宣称等于单篇质量认证。Crossref 无核心标记，保持该要求时不降级；用户主动取消后才可自动备用检索。
3. DOI 精确查询与关键词推荐区分，直接获取登记并明示不应用筛选。缺失信息保留空值，错误不回退为假数据。来源名称、记录、DOI、采集时间可追溯。
4. 真实验收发现 OpenAlex 2024 / Crossref 2025 年份差异，核查面板显示差异和版本核对提示；不擅自统一收藏元数据。支持带尖括号等历史 DOI，以真实登记验证 URL 编码。
5. 文献库按项目隔离，一篇多分类，分类可建/改名/删除；删分类保留论文和笔记。用户自建「核心文献」分类与系统来源标记分开。沿用异步本地仓库及修订号冲突保护，旧项目兼容，失败保留编辑。
6. 不添加依赖。服务端固定上游、有界缓存和进程限流，不自动重试；匿名 OpenAlex 当前实际可用，但免费出口共享额度不作长期保证。可选个人密钥仅服务端使用，未代注册、发邮件、购买服务。
7. 最终 37 项隔离自动测试通过，另用真实两主题、三篇 DOI 抽查及一条真实 AI 关键词建议验收；截图来自实际生产浏览器。保留已确认材质，不重新设计首页。
8. 仍未配置 Supabase，不宣称云同步。不公开部署，停在阶段 3；星图、设计及导出尚未开始。
