## 已确认的问题及修复

### 模型关系与假设

代码证据显示：变量步骤本身不会生成假设；旧图只依据 `hypotheses` 绘制，因此“有变量、无假设”能复现只有节点的状态。旧界面缺少清楚的原因和下一步。同时，服务端把新假设硬限制为最多三条，确实会阻断验收要求中的四段并行中介路径及独立调节假设。没有用户现场保存数据，不能据此断言其那次缺线只有一个具体原因。

现已明确展示“当前只有变量，尚未确认变量间的假设关系，因此不显示连线”，提供用户主动点击的假设梳理入口。新生成最多八条有理由的候选，不为数量凑线；描述中介时须将需要的每段关系分别结构化。仅有角色、题名或文字总述都不会自动产生关系。

`kind`、`moderatesId` 是向后兼容的可选字段。直接关系及中介各段仍由实际假设的起止变量表达；纯调节假设还需明确调节变量和同一列表中的目标关系。服务端拒绝无效端点、自指、未知目标和含糊的新调节结构。图中 W 的紫色虚线指向被调节路径，不额外产生 W→Y 或重复直接效应。旧 `moderatorId` 合并记录原样保留并标记待核对，不升级为新的已确认直接效应。

编辑名称、角色、端点、调节目标与调节变量会更新图和待确认状态；适用的文字名称同步更新，仍提示核对表述和依据。删除目标关系或变量会同步删除依赖的调节，不留悬空引用；旧版本历史保留。手动新增关系必须先选择端点或目标，再点击添加；打开表单或仅选择变量不会产生连线。

五变量显式测试模型为 760×258 的 SVG 视图，使用紧凑分层与折线路由，假设编号和状态可追溯、可键盘进入编辑。长名称换行并保留完整提示。桌面图区域完整呈现主要路径；390px 使用有文字说明的横向滚动。图方向只是拟检验关系，不表示因果已经证实。

### 概念到图书馆

已选概念旁只保留一组主要操作：直接在新标签页打开学校图书馆、复制当前概念词、进入文献工作台。移除了整块检索准备、四张空占位卡和重复生成／保存／跳转按钮，不以新名字搬运原有大卡。图书馆入口不依赖 AI，不索取学校账号，不假装接入数据库。

已有检索词只在默认收起的“高级检索词（可选）”内供参考，原存储保持不变。首页旧概念／图书馆链接修正至独立概念页。

### 研究对话

仅调整研究脉络的聊天区域，保留 Hero 的青紫深蓝品牌色，使用更通透的玻璃层、青紫桃色柔光、内层气泡和输入区；主页和灵感实验室没有重做。短对话不再强撑 760px 留白，长历史按视口滚动，输入框紧凑且不覆盖回复。

实测还定位到 CSS 压缩器将标准 `backdrop-filter` 丢弃的问题；修正前缀声明顺序后，浏览器实际计算出的背景模糊生效，并以自动化断言核对，没有用截图假装滤镜已应用。
