## 尚未实现及明确限制

- **BibTeX / RIS 批量导入**未实现。先用搜索栏输入 DOI，向 Crossref 取得真实登记题录后收藏；这避免把未核对的导入文本误当作已经验证的来源。批量格式解析、字段映射与重复合并留作后续，文档允许后置。
- **PDF 导出**未实现；已提供可继续修改的 Markdown。复杂排版与长文分页后置。
- OpenAlex / Crossref 的中文、摘要及引用关系覆盖有限。没有付费数据库全文、知网/万方抓取，也不会补造缺失论文和引用边。
- 相关性复核由已有 AI 服务辅助，并用真实原文片段约束。仍可能判断错误；有摘要不代表读过全文，有限检索不能证明“无人研究”。
- 没有自动生成与选择额外付费服务。真实 AI 使用现有 DeepSeek 余额；普通元数据请求依来源当前规则及额度执行。上游失败显示错误，需用户手动重试。
- 检索建议缓存按当前观察、已选概念和已确认问题判定是否过时；已保存的脉络也会在概念/文献变化后提示重新核对。

## 三个真实案例

这里的调用实际经过已配置的 DeepSeek、OpenAlex；不是自动化测试的夹具。完整实际响应与失败记录见 [真实接口与交互证据](v12-live-evidence.json)。

### A · GEO 与广告传播

输入使用需求原文的 GEO 情境。AI 返回候选概念，实际选择了说服知识、算法信任与建议采纳。

- 不填写研究种子即可生成双语词组并开始检索。
- 实际查询 `generative engine optimization consumer persuasion knowledge trust`；取得10条真实记录。
- 初评：3篇直接相关、4篇背景、2篇信息不足、1篇不推荐。低相关记录没有作为直接推荐展示。
- 收藏 `Responsible Generative Engine Optimization: Optimizing LLM Rankings via Trustworthy Text Generation`，保留 OpenAlex 来源。它未提供 DOI，不伪造 DOI；此题录不能据此视为已通过同行评审的权威结论。
- 这篇新记录未返回可画引用边，界面如实提示。成功完成单篇有限脉络分析与定量方案，8个AI节点加1个来源线索，编辑确认后保存并重新打开9个节点。

### B · 反向营销与心理逆反

输入使用需求原文的反向营销情境，选中“心理逆反”。

- 开发中第一组长查询返回10篇不相干记录，全部被标记为不推荐，没有伪装成有效成果。
- 据此收紧规划策略，新的实际建议为 `psychological reactance consumer behavior`，直接检索，无需正式问题。
- 第一次复核因AI输出未完整结束返回502；原始题录保留，未伪造评估。补足输出预算并约束字段长度后，同一检索手动重试成功。
- 最终10篇初评：3篇直接相关、5篇背景、2篇信息不足。
- 实际收藏 **Consumer Behavior and Psychological Reactance**，Mona A. Clee、Robert A. Wicklund，1980，DOI [10.1086/208782](https://doi.org/10.1086/208782)。它可帮助理解心理逆反与消费，不等于已证明“品牌劝退必定促进购买”。
- 以该文献为中心读取 **13节点、12条真实引用边**。进一步在浏览器实际拖动、缩放、点击详情，切换中心到 *A Theory of Cognitive Dissonance*，接口返回200。
- 选定论文直接分析脉络，再加入设计。生成9个质化AI节点，连同来源线索共10节点；修改研究内容、确认、保存、刷新恢复。

### C · 跨项目隔离与旧版升级

- 完成B后逐字段比较A：A项目内容未变化。
- 切回A恢复其9节点定量设计与GEO检索词；返回B恢复10节点质化设计与心理逆反检索词。各自概念与收藏独立，刷新后仍正确。
- 另外导入测试环境中实际保存的旧V1.1浏览器状态：2个项目，分别4/6条聊天、0/1篇收藏。新增工作台节点并保存后，原有探索、研究种子、分类、笔记与收藏逐字段不变，额外AI调用0次。
- 该兼容性验证针对我们已有验收样本；不会访问或修改你Mac浏览器里的数据。

## Mac 最简安全更新

**保留旧文件夹、原浏览器和原网址，不清空浏览器数据。** 新代码文件夹不会自动删除浏览器中保存的项目。

1. 记下旧版地址：若原来是 `http://localhost:3000`，继续用它；若原来是 `http://127.0.0.1:3000`，继续用后者。这两个地址的浏览器数据彼此独立。
2. 在旧版启动终端按 **Control + C** 停止。保留旧项目文件夹，暂不要删除。
3. 在 GitHub 的 `codex/paperi-stage1` 分支下载最新版 ZIP，解压到一个新文件夹。聊天交付中会提供本次提交的固定版本下载链接；不要误下载仍是旧版的 `main`。
4. 将旧文件夹里的 **`.env.local`** 复制到新文件夹，和 `package.json` 放在同一层。Finder看不到隐藏文件时按 **Command + Shift + .**。密钥只留在自己的电脑，不发聊天、不上传GitHub。云环境的密钥不会自动包含在ZIP里。
5. 用 VS Code「文件 → 打开文件夹」打开新文件夹。选择「终端 → 新建终端」，依次复制粘贴下面三行，每行运行完成再执行下一行：

```bash
npm ci
npm run build
npm run start -- --hostname 127.0.0.1
```

6. 保持终端开启，用**原来的浏览器和原来的地址**打开。先检查旧项目、笔记和收藏，再开始新探索。只有提示端口占用时，回旧终端停止旧服务，不要为了启动方便随意换端口。

已在使用V1.1的Mac一般无需重装Node；若提示Node版本过低，安装Node.js 24后重开VS Code。第一次启动尚未配置AI也能检查项目和编辑画布；AI配置方法见 [AI设置](AI_SETUP.md)。

如果项目列表忽然空了，先核对地址、端口、浏览器及是否误用了无痕窗口，**不要清理数据或重新建同名项目**。遇到格式异常提示，应用会暂停保存保护原记录。可先停止新版并保留两个文件夹，再反馈具体提示。

当前Codex环境没有可供用户访问的私有浏览器预览入口；`127.0.0.1`只有在服务已启动的那台电脑上有效。没有擅自公开部署、开公网隧道或购买托管。

## 关键实现位置

- `src/lib/workbench.ts`：兼容新增状态、来源约束、项目上下文、Markdown导出。
- `src/components/project-provider.tsx`：工作台独立版本与存储保护。
- `src/components/literature.tsx`：查询来源、短查询合并、相关性显示、分类收藏与共享选文献。
- `src/lib/research-server.ts`：关键词、相关性、脉络与设计AI接口；严格校验输入/输出来源ID。
- `src/lib/graph-server.ts`：固定OpenAlex域名、中心核验、真实引用边、一层有界请求与缓存。
- `src/components/node-canvas.tsx`：SVG交互、拖动/键盘移动、平移、缩放与适应视图。
- `src/components/research-map.tsx`、`design-canvas.tsx`：星图、脉络、定量/质化编辑工作台。
- `tests/workbench.spec.ts`：V1.2新增的共享状态、引用、设计、错误与响应式回归。
