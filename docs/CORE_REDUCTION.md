# Paperi 核心收拢 · 两阶段交付记录

基线：`f5ec6be`，分支 `codex/paperi-stage1`。按用户上传的《核心产品收缩与视觉一致性重构》实施，保留 `paperi.projects.v1`、项目 JSON 备份及 PDF IndexedDB；没有初始化仓库或清空数据。

## 阶段一：核心产品

- 主导航仅首页、灵感实验室、文献工作台；四个旅程步骤为灵感、概念、图书馆、文献。撤下星图、研究整合/设计/框架主入口。旧 `/map`、`/review`、`/canvas`、`/proposal` 重定向至研究脉络；旧综述/设计内容只读保留，完整数据仍包含在备份中。
- 当前项目原始输入沿用既有 Hero 自动首轮机制。概念 schema 容纳一轮 12 个候选，提示目标 8–12 个、解释、关联、分组和边界；不能保证每次足够 12 个，不凑造术语。保留选择/排除/编辑与追加不覆盖机制。探索一次请求预算 5000 token，明确截断，不自动多次重试。
- 点击已选概念的检索准备入口后，先读配置状态；有配置且本项目上下文尚未生成时，自动进行一次关键词请求并保存，同一会话上下文不循环重试。不配置或失败仍显示可复制的已选概念；可手动重试。图书馆使用新标签，不接学校 API 或登录；支持修改 URL。
- 多文件导入原机制保留，增加前三页文字中的标题/作者/年份/刊物/DOI/摘要候选识别。只提取实际存在的字段，附原文页码，用户确认；缺字段留空。展示文件保存、文字页数/字数、书目候选及精析是否已有记录。未增加 AI 元数据收费请求。
- 一键精析由十维压为七维：30 秒读懂、研究动机、理论概念、方法过程、关键发现、局限/启发、项目价值。正文节选保持首尾与方法/结果覆盖，不假装阅读全文；每项可展开原文依据及页码。只有题录走确定的资料不足说明，不调用模型猜方法结论。可保存阅读笔记，分析历史持续保存。
- “梳理研究脉络”一次请求同时返回跨文献对照和 2–3 条有差异的方向（不足可少给）。事实归纳引句必须匹配资料，无法匹配的判断降为资料不足；方向为研究提议，附具体论文，不等于事实。
- 终点为可编辑方向卡：问题、价值、论文依据、初步方法和待核实事项；可保存、复制普通文字、打印。方向改变不使自身无端失效；文献变动/删除仍提示更新。失败不覆盖已保存卡。不再要求综述、模型、Markdown 导出。

阶段一验证：lint、typecheck、build 通过；8 项定向回归通过（25.3 秒）。包括混合导入/多个 PDF、模型协议、概念流转、方向卡编辑刷新复制、项目隔离、旧路由/数据兼容及恢复副本删除不影响原 PDF。模型回复与文字 PDF 为明确模拟；不是实际 AI 研究成果。阶段提交 `294cde1` 已正常推送。

测试调整：已退役星图、旧画布、综述导出流程的 UI 测试原文保留在 `tests/retired-ui/`，不作为当前产品通过项。旧存储/适配器的数据与 API 测试仍运行；PDF 原件保护的浏览器回归已独立保留，新核心旅程替代原产品导航验收。

## 阶段二：视觉与阅读

- 保留 Hero，主对话使用同源深蓝底、紫/青柔光、浅色正文及清晰焦点。聊天全宽，长回复与输入区分占独立空间；输入区保持紧凑，不悬浮遮挡。其他内容延续多色浅磨砂。
- 概念移出窄侧栏，按模型提供的分组排列，桌面 3 列、平板 2 列、手机 1 列；一次先显示最多 12 个，更多可展开。已选概念集中可见，修改时保留分组和关联说明。
- 精析采用论文身份头部、30 秒读懂重点块、章节导航与独立阅读区域。紫/绿/桃分区、17px 正文与约 2 倍行距，原文证据和资料限制折叠，手机单栏。
- 方向卡保存后默认阅读版，需要时展开编辑。复制普通文字，打印只保留卡片内容，避免操作按钮或应用导航进入打印页。旧数据不改写。
- 补充“AI 已返回但存储失败”独立重试保存，不重复模型调用；关键词配置检查与请求有等待上限。
- 一次完整回归 **68/68 通过（1.7 分钟）**；此后新增保存恢复、最终视觉/打印收尾的定向回归 **7/7 通过（36.8 秒）**。覆盖 1440px 与 390px 实际 Chromium 渲染、深色背景、聊天阅读区大于输入区、精析章节间距、方向卡阅读/编辑/打印，以及核心数据流。测试失败的两处初始视觉断言因夹具标题不一致而修正，同时修正了打印样式优先级；没有把失败项跳过。
- lint、typecheck、最终生产 build 通过；开发模式 PDF 单独复验 **1/1 通过（17.8 秒）**，没有浏览器 pageerror。生成并实际查看了 `docs/screenshots/core/` 的聊天、精析、方向卡截图；所有分析文字标注为布局夹具，不宣称是真实研究成果。

## 真实能力边界

云端没有真实 AI 密钥；用户本轮未提供三篇真实中文 PDF。因此**尚未在真实用户条件下验证**“三篇中文论文 → 精析正确性 → 跨文献脉络 → 有学术价值的方向卡”，不能宣称核心研究闭环已通过真实验收。测试中的期刊社真实书目仅证明导入/存储，不代替实际 PDF 或 AI 能力。扫描 PDF 无 OCR。正文候选识别对复杂版式/无标签作者年份会缺失，需要用户核对；没有把缺字段猜成事实。

本轮不调用付费 API，不恢复站内搜索/引用网络，不新增收费平台。真实模型调用次数与成本均为 0。

## Mac ZIP 更新与最少真实复验

下载目标分支 ZIP，保留旧目录，把 `.env.local` 仅本地复制到新目录，运行 `npm ci` 和 `npm run dev`，沿用同一浏览器及 `http://localhost:3000`。不要清站点数据；更换环境前先导出项目备份并另存 PDF。

现有 `AI_API_KEY/AI_BASE_URL/AI_MODEL` 配置保持兼容，或使用服务端 `DEEPSEEK_API_KEY`；不使用 NEXT_PUBLIC 密钥，也不要在聊天中发送密钥。自动关键词发生在用户进入检索准备后，失败不自动重试。

最低真实验证约 4 次模型请求：Hero 首轮概念 1 次、进入图书馆准备关键词 1 次、实际 PDF 一键精析 1 次、三篇资料研究脉络 1 次。不要连续盲重试。用自己的三篇中文文字 PDF 一次导入，确认页数/字数及候选字段后，逐项核对精析的方法/发现是否在对应页码，比较脉络与各篇内容，再保存复制方向卡。错误时保留项目和错误原因，不提供 Authorization 请求头。真实费用以服务商账单为准。
